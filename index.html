OOP Architecture

This dashboard was built applying Object-Oriented Programming principles — Analysis, Design, and Implementation — using vanilla HTML, CSS, and JavaScript ES6+ classes. No external UI frameworks are required.

🔒 Encapsulation

Private fields (#) hide internal state; public APIs expose only needed behaviour.

🧬 Inheritance

StatWidget, ChartWidget, TableWidget all extend Widget → Component.

🎭 Polymorphism

Each widget overrides buildBody() providing a different visual output via the same interface.

🧩 Abstraction

Component and Widget are abstract; they define contracts without dictating implementation.
